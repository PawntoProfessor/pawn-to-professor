# Pawn to Professor

A browser-managed teaching hub for EFL lessons, HTML5 games, flashcards, worksheets, chess resources and teacher materials.

## Daily owner workflow
Use `/admin`. You do not edit GitHub for normal content management.

## Included
- Responsive public website
- Database-driven top navigation
- Unlimited section/sub-section tree
- Pages and resource manager
- HTML5 game links
- Hide/show controls
- Up/down ordering
- Soft-delete Trash + Restore
- Media Library (Supabase Storage)
- Editable website branding/header/homepage
- Admin authentication
- Supabase Row Level Security
- Vercel-ready Next.js 16 app
- Safe demo homepage before Supabase is configured

## Setup
Read `SETUP-GUIDE.md`.

## No mail server
This version intentionally includes no mail server and no transactional email dependency.
